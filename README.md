# Regression-Analysis
Regression analysis can be performed. Quantification theory is utilized to handle a mix of quantitative and qualitative variables.

# 回帰分析 自動分析　マニュアル

## 1. はじめに（本ツールの目的）

本ツールは、複雑な統計ソフトの設定に迷うことなく、ブラウザ上で直感的に回帰分析を実行できるアプリケーションです。
データの内容（連続値か、0/1のダミー変数か）をシステムが自動で読み取り、「重回帰分析」「ロジスティック回帰分析」「数量化1類・2類」の中から最適な手法を自動選択します。さらに、論文執筆（APA第7版準拠）にそのまま使える記述テンプレートや、JASP（無料統計ソフト）用のRコードも自動生成します。

---

## 2. 【重要】分析を始める前の準備（初心者の落とし穴）

ツールを動かす前に、エクセル等で作成する**「データの形（CSVファイル）」**が以下のルールを満たしているか確認してください。ここを間違えるとエラーになります。

- **ルール①：1行目は必ず「変数名（タイトル）」にする**
  - ⭕️ 良い例：`テスト得点`, `学習時間`, `性別`
  - ❌ 悪い例：1行目に「A組のデータ」などのメモを書かない。
- **ルール②：文字データは「数値」に変換する（ダミー変数化）**
  - 回帰分析では「男」「女」や「あり」「なし」という文字を計算できません。
  - 必ず、置換機能を使って **「0」と「1」の数値** に変換してください（例：男子＝0、女子＝1）。
- **ルール③：空欄（欠損値）の扱い**
  - アンケートの未回答など、セルが空欄の行がある場合、本ツールは「その生徒のデータ行全体」を自動的に計算から除外（リストワイズ削除）します。

---

## 3. 基本的な操作手順

ここでは、**「テストの得点」** を、**「学習時間（時間）」** と **「塾の有無（0=なし, 1=あり）」** から予測するという具体例で解説します。

### Step 1: データの読み込み
1. 準備したCSVファイルを、画面上部の点線エリアにドラッグ＆ドロップします。
2. `✅ 読み込み完了` と表示されれば成功です。

### Step 2: 変数と投入方法の設定
画面に変数の一覧が表示されます。
1. **目的変数（1つ選択）**: 予測したい結果です。例では「テストの得点」の `〇` を選択します。
2. **説明変数（複数選択可）**: 原因となる変数です。例では「学習時間」と「塾の有無」の `☑` を選択します。
3. **投入方法の選択**:
   - **強制投入法**: 選んだ変数をすべて計算に入れます（基本はこちらを使用）。
   - **ステップワイズ法**: コンピュータが予測に役立つ変数だけを自動で絞り込みます。

### Step 3: 分析の実行
「分析を実行する」ボタンをクリックすると、一瞬で画面下部に結果が表示されます。

---

## 4. 分析結果の読み方と、論文への書き方

結果画面には、大きく分けて3つの情報が表示されます。

### ① 判定された手法と無相関検定・VIF（多重共線性）
**VIF（分散拡大要因）** の数値を確認します。説明変数同士が「似たような意味」を持ちすぎていないかのチェックです。
> ⚠️ **注意:** VIFが **5.0以上** の場合、多重共線性（ダミー変数の罠など）が発生しており、結果が歪んでいます。相関の高い変数のどちらかを分析から外してください。

### ② APA記法テンプレートとJASPの連携
ブラウザの計算能力には限界があるため、高度な検定は無料の統計ソフト「JASP」を用いて行い、その数値をテンプレートに当てはめます。

**【JASPでのコード実行手順】**
1. アプリ画面下部の「📋 Rコードをコピー」ボタンを押す。
2. JASPを起動し、右上の「＋」ボタンから **R (Beta)** モジュールを有効化する。
3. Rコンソール画面にコードを貼り付けて実行（`Ctrl + Enter` 又は `Command + Enter`）する。

**【出力結果とテンプレートの対応表】**

| JASP Rコンソールの表示 | 見るべきポイント（事実） | APAテンプレートでの表記例 |
| :--- | :--- | :--- |
| `Adjusted R-squared` | モデルの説明力（当てはまりの良さ） | 調整済み決定係数は $R^2_{adj} = 0.45$ であった |
| `F-statistic`, `p-value` | モデル全体が有用か（p < .05 で有意） | $F(2, 146) = 15.4, p < .001$ |
| `Estimate` 又は標準化係数 | 変数の影響力の強さと向き（+, -） | $\beta = 0.34$ |
| `Pr(>\|t\|)` | その変数の影響が有意か（p < .05） | $p = .012$ |
| `DW` (Durbin-Watson) | 残差に自己相関がないか（2に近いか） | $DW = 1.95$ |

---

## 5. 【コラム】事実と推測を分ける（分析の限界）

データ分析の初学者がレポートを書く際、最も陥りやすい罠が「相関と因果の混同」です。

> 💡 **事実と推測の明確な分離**
> 
> **【事実】データが示していること**
> 「塾の有無（あり＝1）の偏回帰係数が正であり、p値が.05未満であった」というのは統計的な事実です。これは単に「塾に行っている生徒のほうが、テストの点数が高い傾向（相関）がある」ことを示しています。
> 
> **【推測】因果関係の飛躍に注意**
> これを「塾に行けばテストの点数が上がる（因果関係）」と断定することはできません。「もともと学習意欲の高い生徒が塾に行っているだけ」かもしれないからです。
> 
> 論文やレポートでは、断定を避け、**「〜という影響を与えていると推測される」「〜という可能性が示唆された」** と、事実に基づいた推測として慎重に表現してください。
